## 🎨 About This Portfolio

This portfolio website is built with a unique **macOS/VS Code hybrid interface**, creating an immersive desktop experience. It showcases my work through interactive windows, a terminal interface, and a code editor display.

### 🛠️ Built With

- **Framework**: Vue 3 (Composition & Options API)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with custom macOS/VS Code themes
- **Animations**: GSAP
- **3D Graphics**: Three.js
- **Contact Form**: EmailJS
- **Responsive Design**: Mobile-first approach with desktop enhancements

### ✨ Features

- Interactive macOS-style desktop interface
- Draggable and resizable windows
- VS Code-inspired skills display with syntax highlighting
- Interactive terminal with real commands
- Finder-style project browsing
- Fully responsive (mobile to desktop)
- Smooth animations and transitions
- Dark mode design

### 🚀 Key Highlights

- **Glassmorphism**: Frosted glass effects on windows and dock
- **Touch Support**: Mobile-friendly with touch interactions
- **Window Management**: Minimize, maximize, close with macOS traffic lights
- **Dock**: Bottom navigation with hover magnification (desktop) and tap interactions (mobile)
